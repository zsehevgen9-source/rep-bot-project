# Мини-приложение «Маячок»

Приложение — это веб-страница, которую MAX открывает внутри чата с ботом.
Страницу и её данные отдаёт сам бот: внутри него работает небольшой веб-сервер на порту **8080**.

```
Телефон (MAX) ──https──▶ сервер: Caddy :443 (сертификат Let's Encrypt) ──▶ бот :8080 (страница + /api)
```

На сервере HTTPS включается одной командой `bash scripts/server_https.sh` — см. шаг 7 в `docs/SERVER.md`.
Дома (для проверки) можно по-прежнему использовать туннель Tuna.

## Что внутри

| Раздел | Что там |
|---|---|
| 🏠 Главная | очки, серия дней, цель недели, 🎁 сундук дня, 🗼 мой маяк, уроки по расписанию на сегодня, темы «пора повторить» |
| 🎯 Тренажёр | тест по любому предмету или теме прямо в приложении; итог, очки, уровень; ошибки — разбор в чате |
| 📊 Прогресс | график недели, предметы и темы, оценки за уроки, достижения |
| 🗓 Расписание | уроки по дням: добавить, переставить, убрать |
| 💬 Маячок | чат с ботом прямо в приложении: всё, что умеет бот в MAX — уроки и «объясни по-другому», задания дня, помощь с домашкой по фото, подготовка к ВПР/ОГЭ/ЕГЭ и пробные варианты, задания учителя и фото решения. Ответы приходят в приложение, а не в чат MAX |
| 👋 Знакомство | «Я ученик / Я родитель / Я учитель»: согласие на обработку данных, имя, класс (часовой пояс — с телефона); родитель — по коду ребёнка; учитель — кабинет сразу |
| ⚙️ Настройки | имя, класс, увлечения, код для родителя и отключение родителей, вступить в класс учителя / выйти, политика, удаление данных |
| 👩‍🏫 Кабинет учителя | профиль (начальные / предметник, предметы, имя), классы (создать, подключиться по коду, удалить), ученики и их отчёты, слабые темы, задание классу, результаты с оценками, фото решений, напоминание |
| 🎮 Игры | ⚡ Молния (живой таймер 60 с, 3 жизни, рекорды; счёт проверяет сервер), 🃏 Карточки (переворот, «Помню / Не помню», интервалы), 🎁 Сундук дня с анимацией и 📒 альбом наклеек, 🗼 Мой маяк |
| 👨‍👩‍👧 Кабинет родителя | отчёт за неделю, оценки, слабые темы, прогресс и расписание ребёнка |

Данные — те же, что в чате: приложение и бот работают с одной базой.

Показать другие роли в демо (открыто не из MAX): `?demo=new`, `?demo=teacher`, `?demo=parent`.

## Безопасность
- Каждый запрос подписан MAX (`initData`). Сервер проверяет подпись токеном бота — подделать пользователя нельзя.
- Родитель видит только детей, которые сами дали ему код.
- Открытое не из MAX (например, в браузере) приложение показывает **демо-режим** с выдуманными данными.

## Файлы
- `app/webapp/static/` — страница (HTML, CSS, JS).
- `app/webapp/api.py` — данные для страницы.
- `app/webapp/server.py` — веб-сервер.
- `app/webapp/auth.py` — проверка подписи MAX.

## Настройки `.env`
```
WEBAPP_ENABLED=true     # веб-сервер приложения
WEBAPP_PORT=8080        # порт
MINIAPP_BUTTON=false    # кнопка «📱 Открыть приложение» в меню бота (включить после подключения в MAX)
MAX_BOT_USERNAME=       # имя бота; если пусто — бот узнает его сам
```

## Туннель Tuna (адрес https для домашнего компьютера)
1. Установка (PowerShell): `winget install --id yuccastream.tuna`
2. Вход: `tuna login`
3. Запуск: `tuna http 8080 --subdomain=ВАШ_ПОДДОМЕН`, где поддомен — из раздела «Домены» в личном кабинете Tuna.
4. Адрес приложения: `https://ВАШ_ПОДДОМЕН.ru.tuna.am` — его вставляют в настройках бота на платформе MAX.

Окно с туннелем должно быть открыто, пока работает бот.
