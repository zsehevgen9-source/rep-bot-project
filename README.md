# Маячок — ИИ-репетитор в мессенджере MAX

Команда «Маяк» · конкурс «Идея.Фикс»

**Маячок** — личный репетитор для школьников 1–11 классов прямо в чате [MAX](https://max.ru). Он знает школьную
программу по четвертям, занимается по расписанию уроков ученика, объясняет темы по выбранному учебнику и ведёт
к ответу подсказками — **не решает за ребёнка**. Родители получают еженедельный отчёт.

- Рабочие программы школы (КТП 2026/27): ~6000 тем уроков с датами для 1–11 классов, тема дня — по дате урока
- Входной тест в предмете → урок по теме (объяснение → пробный пример → задания на оценку → оценка 2–5)
- Тесты и задания от YandexGPT с перепроверкой; собственный банк проверенных заданий
- Расписание кнопками, текстом, фото или файлом; занятия по сегодняшним урокам, мини-тест по пятницам
- Помощь с домашкой по фото (Yandex Vision OCR) — подсказками, без готовых ответов
- Подготовка к ВПР, ОГЭ и ЕГЭ
- Очки, уровни, серия дней, 16 достижений, грамоты; картинки-карточки с результатами
- Голос Маячка (Yandex SpeechKit): каждое сообщение дублируется голосовым
- Режим родителя: подключение по коду, отчёт по воскресеньям, расписание за ребёнка
- Кабинет учителя: класс по коду, отчёты учеников, слабые темы класса, задания всему классу с оценками
- Мини-приложение MAX: всё то же, что в боте, плюс игры, голос и гайд по приложению (`app/webapp`, см. `docs/MINIAPP.md`)
- Игры: «Мой маяк» (серия дней), «Сундук дня» с альбомом наклеек, «⚡ Молния», карточки с интервальным повторением
- Работает круглосуточно на сервере: переезд с компьютера вместе с данными — `docs/SERVER.md`

## Как проверить проект

Ключи от MAX и Yandex Cloud в репозиторий не выкладываются: в `.env` секреты команды, а в базе — данные учеников.
Поэтому есть три способа проверки — от самого быстрого к полному.

**1. Живой бот (ничего ставить не нужно).** Бот работает круглосуточно на сервере команды с нашими ключами
Yandex Cloud. Ссылка на бота в MAX — в заявке. Напишите ему `/start`, выберите «Я ученик», «Я родитель» или «Я учитель».

**2. Мини-приложение в браузере, демо-режим (без MAX и без регистрации).** Данные выдуманные, все экраны настоящие:

- ученик: https://84-54-57-198.sslip.io/
- учитель: https://84-54-57-198.sslip.io/?demo=teacher
- родитель: https://84-54-57-198.sslip.io/?demo=parent
- новый пользователь (выбор роли, гайд): https://84-54-57-198.sslip.io/?demo=new

**3. Свой запуск из кода.** Нужны свой токен бота MAX и (для ИИ, голоса и распознавания фото) свой ключ Yandex Cloud —
см. «Быстрый старт» ниже. Без ключа Yandex Cloud бот тоже запускается, но задания берёт только из встроенного банка,
а объяснения нейросети, голос и фото домашки работать не будут.

Автотесты всего бота (больше 1000 проверок сценариев ученика, родителя, учителя и мини-приложения) не требуют ни ключей,
ни интернета:

```bash
pip install -r requirements.txt
python tests/test_bot.py          # в конце: «ВСЕ ПРОВЕРКИ ПРОЙДЕНЫ»
```

## Стек

- Python 3.12, asyncio, aiohttp (long polling к MAX API, веб-сервер мини-приложения)
- PostgreSQL + SQLAlchemy 2.0 (async) + Alembic: профили учеников, прогресс, расписание
- Redis: состояние диалогов, банк заданий (при недоступности Redis бот временно работает на памяти процесса)
- YandexGPT, Yandex SpeechKit, Yandex Vision OCR
- Pillow: картинки-карточки и талисман Маячок (рисуется кодом)
- Docker Compose

## Быстрый старт

Нужны: [Docker](https://docs.docker.com/get-docker/) с Docker Compose, токен бота MAX и ключ Yandex Cloud.

1. Скачайте проект и создайте файл настроек `.env`:

   ```bash
   git clone https://github.com/zsehevgen9-source/rep-bot-project.git
   cd rep-bot-project
   cp .env.example .env          # Windows (PowerShell): copy .env.example .env
   ```

2. Откройте `.env` и заполните три строки:

   ```ini
   MAX_BOT_TOKEN=токен бота из кабинета разработчика MAX
   YANDEX_API_KEY=API-ключ сервисного аккаунта Yandex Cloud
   YANDEX_FOLDER_ID=ID каталога Yandex Cloud
   ```

   Остальные настройки уже заполнены рабочими значениями (описание — прямо в `.env.example`).

3. Соберите образ и запустите бота вместе с базой и Redis:

   ```bash
   docker compose up -d --build
   ```

4. Проверьте, что всё запустилось:

   ```bash
   docker compose ps               # bot — running, db и redis — healthy
   docker compose logs -f bot      # в логах: «Ссылка на бота: https://max.ru/...»
   ```

   Мини-приложение открывается на http://localhost:8080 (вне MAX — в демо-режиме).
   Напишите боту в MAX `/start` — он ответит.

Остановка: `docker compose down`. Таблицы базы создаются сами при первом запуске (миграции Alembic).
Короткие команды есть в `Makefile` (`make up`, `make logs`, `make migrate`).

## Docker-образ

Образ описан в `Dockerfile` в корне проекта: Python 3.12-slim, библиотеки из `requirements.txt`,
ffmpeg (голос), шрифты для картинок-карточек. Бот внутри работает от обычного пользователя, не от root.

### Сборка и запуск контейнера вручную (без Compose)

Боту нужны PostgreSQL и Redis. Пример целиком из командной строки:

```bash
# 1. Сборка образа
docker build -t mayachok .

# 2. Общая сеть, база и Redis
docker network create mayachok-net
docker run -d --name mayachok-db --network mayachok-net \
  -e POSTGRES_USER=user -e POSTGRES_PASSWORD=password -e POSTGRES_DB=bot_db \
  -v mayachok-pg:/var/lib/postgresql/data postgres:15-alpine
docker run -d --name mayachok-redis --network mayachok-net redis:7-alpine redis-server --appendonly yes

# 3. Запуск бота (токены берутся из .env)
docker run -d --name mayachok-bot --network mayachok-net --env-file .env \
  -e DATABASE_URL=postgresql+asyncpg://user:password@mayachok-db:5432/bot_db \
  -e REDIS_URL=redis://mayachok-redis:6379/0 \
  -p 127.0.0.1:8080:8080 --restart unless-stopped mayachok

# 4. Логи и остановка
docker logs -f mayachok-bot
docker stop mayachok-bot mayachok-redis mayachok-db
```

В Windows PowerShell перенос строки — обратная кавычка `` ` `` вместо `\` (или пишите команду в одну строку).

### Команды внутри контейнера

```bash
docker compose exec bot python -c "import app.main" && echo OK            # проверить, что код бота загружается
docker compose run --rm bot alembic upgrade head                        # применить миграции вручную
docker compose exec db psql -U user -d bot_db                           # консоль базы данных
```

### Запуск без Docker (для отладки в VS Code)

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
docker compose up -d db redis    # только база и Redis
python -m app.main               # запуск бота из командной строки
```

Для голоса нужен установленный `ffmpeg` (в Docker-образе он уже есть).

## Работа круглосуточно (сервер)

Чтобы бот работал при выключенном компьютере, его переносят на виртуальный сервер (Yandex Cloud или любой VPS с Ubuntu)
вместе со всеми данными — пошагово в `docs/SERVER.md`. Скрипты: `scripts/export_data.ps1` (сохранить данные дома),
`scripts/server_setup.sh` (подготовить сервер), `scripts/server_import.sh` (первый запуск с данными),
`scripts/server_update.sh` (обновление кода).

## Голосовой ввод

В мини-приложении ученик отвечает голосом кнопкой 🎤 (запись до 30 секунд, распознаёт Yandex SpeechKit),
Маячок пишет «🎤 Я услышал: …» и отвечает как на текст. В чате бота распознаются голосовые сообщения, если MAX
передаёт их ботам; иначе ученик отвечает кнопками или текстом.

## Голос бота

- Каждый ответ бота приходит **одним голосовым**: текст режется по предложениям, куски озвучиваются одновременно
  и склеиваются с короткими паузами (ffmpeg). Перед озвучкой убираются эмодзи, формулы читаются словами,
  сокращения раскрываются («т.е.» → «то есть»), а переносы строк становятся паузами.
- Маячок — мальчик, поэтому голоса мужские. По умолчанию — **Александр, бодрый** (`TTS_VOICE=alexander`, `TTS_ROLE=good`).
  Если голос недоступен, бот сам переходит на запасной (Ермил) и пробует основной снова через час.
  Женский голос из старых настроек автоматически заменяется голосом Маячка.
- Выбрать голос на слух: администратор пишет боту `/voices` — придут образцы всех голосов; `/voice 2` — выбрать
  второй для всех учеников; `/voice 0` — вернуть голос из `.env`.

## Тест по предмету и сложность

- «🎲 Тест по предмету» — каждый раз **новый тест**, который составляет ИИ: 5 вопросов с 3 вариантами в 1–4 классах,
  7 вопросов с 4 вариантами в 5–11. В тест обязательно попадают слабые темы и темы, которые пора повторить.
- Каждый вопрос ИИ решает второй раз «с чистого листа»; если ответы не совпали, вопрос выбрасывается. То же — с одиночными заданиями.
- В конце — итог ✅/❌ по каждому вопросу. Правильные ответы бот не показывает: ошибку можно «🔧 Разобрать» с подсказками.
- Сложность подстраивается по каждому предмету: базовый → повышенный (по умолчанию) → высокий. Тест 80%+ — уровень выше,
  меньше 50% — ниже; в обычных заданиях 3 верных с первой попытки подряд — выше, 2 ошибки подряд — ниже.
- Модель ИИ по умолчанию — `aliceai-llm` (самая сильная у Яндекса). Если она недоступна в вашем каталоге,
  бот сам переходит на `YANDEX_GPT_FALLBACK_MODEL` (по умолчанию `yandexgpt-5-pro`).

## Предметы, уроки и расписание

- **Входной тест вместо диагностики при регистрации.** Регистрация: имя → класс → город → меню. При первом входе
  в предмет бот предлагает «🧭 Входной тест»: ИИ составляет его по темам, которые к сегодняшнему дню уже прошли
  (с начала учебного года). Ошибки становятся темами «стоит подтянуть». Общая диагностика осталась в «⚙️ Настройки».
- **Урок по теме.** Ученик пишет тему → бот подробно объясняет её с двумя разобранными примерами →
  «✍️ Пробный пример» (с подсказками, ошибки не считаются) → «📝 Задания на оценку» (4–5 вопросов по теме, без подсказок) →
  оценка 2–5. Оценки видны в «📊 Прогресс».
- **Расписание уроков** («🗓 Расписание» в меню): по дням кнопками или текстом («Пн: математика, русский…», можно
  столбиком, как в дневнике). Уроки без заданий (физкультура, музыка) пропускаются.
- **Расписание фото или файлом.** «🗓 Расписание → 📷 Фото, файл или текст»: фото, скриншот из электронного дневника,
  PDF (одна страница), Word или Excel. Фото и PDF распознаёт Yandex Vision OCR (нужна роль `ai.vision.user`
  у сервисного аккаунта), Word и Excel читаются напрямую. YandexGPT превращает распознанное в «Пн: …, Вт: …»,
  бот показывает «Вот что я понял» и сохраняет только после «✅ Всё верно».
- **Занятия по расписанию.** В 16:00 бот предлагает закрепить сегодняшние уроки: ученик выбирает предмет, бот
  спрашивает тему урока и проводит урок. «🔁 Повторение» — обычный план по слабым темам. По пятницам — мини-тест недели.

## Программы и учебники (1–11 классы)

- `data/programs/programs_1-4.json`, `programs_5-7.json`, `programs_8-9.json` и `programs_10-11.json` — темы по четвертям для каждого предмета 1–11 классов (примерная программа по ФОП НОО, ООО и СОО,
  порядок тем — как в самых распространённых учебниках) и список учебников (авторов) по каждому предмету.
- По дате бот понимает, какие темы уже прошли и какая идёт сейчас: в предмете видно «📚 Сейчас по программе: …»,
  есть кнопки «📘 Урок по программе», «📚 Программа» (все темы по четвертям с отметками ✅ 🔄 ❗ 👉) и «📗 Учебник».
- Входной тест берёт вопросы только из пройденных тем; задания без темы — тоже из пройденного.
- Учебник выбирается отдельно по каждому предмету (из списка или словами). ИИ объясняет и составляет задания
  в терминах этого учебника, но задания из учебника не копирует.
- Темп у школ разный, поэтому на вопрос «какую тему проходили?» бот предлагает тему по программе и соседние,
  а ученик может написать свою.

## Помощь с домашкой

- Кнопка «📸 Помощь с домашкой» в меню: ученик фотографирует задание из учебника или тетради (или пишет его текстом).
- Yandex Vision OCR распознаёт текст, YandexGPT восстанавливает условие, определяет предмет и тему; если на фото несколько
  заданий — ученик выбирает, с какого начать.
- Дальше — как обычное задание бота: подсказки становятся подробнее с каждой попыткой, есть «📖 Объясни тему».
  Ответ бот вычисляет сам и держит при себе: готовые ответы не выдаёт никогда.
- Фото, присланное просто так, бот спрашивает: «📸 Задание — помоги» или «🗓 Это расписание».

## Режим для родителя

- Родитель нажимает «👨‍👩‍👧 Я родитель» (в боте или в приложении) и получает код из 6 цифр (действует 7 дней).
- Ребёнок вводит этот код у себя: «⚙️ Настройки → 👨‍👩‍👧 Родитель → 🔑 Ввести код родителя» или `/family 123456` —
  так же, как ученик вступает в класс учителя. Один код подходит для нескольких детей.
- Запасной способ: ребёнок показывает свой код (действует сутки), родитель пишет боту `/parent 123456`.
  Можно подключить до 3 родителей; у родителя может быть несколько детей.
- Родитель видит отчёт о занятиях за неделю (дни занятий, решено заданий, точность, оценки за уроки, темы для подтягивания)
  и может внести расписание за ребёнка — текстом, фото или файлом, с подтверждением.
- Каждое воскресенье в 18:00 (по времени ребёнка) отчёт приходит родителю сам.
- Ребёнку бот сообщает, когда подключился родитель или внёс расписание; отключить родителей можно в настройках.
- 👏 «Похвалить» — ребёнку приходят слова родителя и бонусные очки (раз в день).
- 🎯 «Цель недели» — родитель ставит число заданий и награду; ребёнок видит прогресс в меню и в приложении,
  а когда выполнит — поздравление приходит обоим.
- 💡 «Как помочь дома» — у слабой темы совет родителю простыми словами (ИИ, один раз на тему, дальше из памяти).
- 🔔 Тревожные сигналы — 3 учебных дня без занятий (в 19:00) или две двойки подряд по предмету; выключаются кнопкой.
- 📈 Сравнение с прошлой неделей в отчёте, в приложении — график за 4 недели.
- Для презентации: `/demo_parent` (администратор) — показать родительский отчёт сразу.

## Для презентации

- `/demo_student 7` (администратор) — заполняет СВОЙ профиль демо-историей за две недели для выбранного класса:
  входные тесты, темы с разными статусами, оценки за уроки, активность, серия, награды, расписание, учебники.
  Перед заполнением бот спрашивает подтверждение: настоящие данные администратора заменяются.
- Дальше: `/demo` — задание на день, `/demo_friday` — мини-тест недели, `/demo_report` — вечерний отчёт,
  `/demo_parent` — отчёт родителю.

## Скорость и расходы

- **Свой банк проверенных заданий.** Каждый вопрос теста и каждое задание, которые ИИ составил и перепроверил, сохраняются
  (Redis, `bank:*`). Следующий ученик того же класса, предмета и темы получает их сразу — без ожидания и без запроса к ИИ.
  Один и тот же ученик одно задание дважды не получает. Объяснения тем к урокам тоже кешируются (по классу, теме и учебнику).
- **Задания на оценку готовятся заранее:** пока ученик читает объяснение и решает пробный пример.
- **Лимит:** `AI_DAILY_LIMIT` в `.env` (по умолчанию 40) — сколько «тяжёлых» действий ИИ (новый тест, урок, разбор фото,
  новое задание, объяснение) можно одному ученику в день. Задания из банка и проверка ответов не считаются, администраторам —
  без лимита. В `/stats` видно, сколько запросов к ИИ было сегодня и сколько заданий в банке.

## Ежедневные занятия

- По будням бот сам присылает **задание на день** (по умолчанию в 16:00) и **вечерний отчёт** (19:30) по местному
  времени ученика (по умолчанию UTC+5). Пишет только с 7:00 до 21:00 и не больше двух сообщений в день.
- План на день: 3 задания в 1–4 классах, 5 — в 5–9, 6 — в 10–11. Сначала слабые темы из диагностики и темы,
  которые пора повторить, затем новые задания по разным предметам (не больше двух по одному предмету).
- **Слабая тема — сначала объяснение.** Перед первым заданием по теме, на которой ученик ошибся в диагностике, бот
  коротко объясняет её: суть, правило, разобранный пример, типичная ошибка. В любом задании есть кнопка «📖 Объясни тему»
  (объяснение на другом примере, ответ на само задание бот не называет).
- **Пятница — мини-тест недели.** Вместо обычного плана бот предлагает сгенерированный тест по предмету, где за неделю
  было больше всего тем (и именно по этим темам). Можно выбрать «📅 Обычные задания».
- **Часовой пояс.** MAX не сообщает боту, где ученик, поэтому после выбора класса бот один раз спрашивает: ученик пишет
  город («я из Казани», «Новосибирск») или нажимает кнопку со временем, как на его часах. Поменять:
  «⚙️ Настройки → 🔔 Уведомления и время → 🕐 Часовой пояс».
- Если ученик 3 учебных дня не отвечает, бот один раз спрашивает «Всё в порядке?» и замолкает, пока ученик не напишет сам.
- Время и отключение уведомлений: «⚙️ Настройки → 🔔 Уведомления и время».

## Режимы и награды

| Режим | Классы | Как выглядит |
|---|---|---|
| Играйка 🎈 | 1–4 | звёзды ⭐ (2 — верно с первой попытки, 1 — после подсказок, 3 — за план на день, 5 — за диагностику), уровни «Звёздочка → Искорка → Комета → Звездочёт → Космонавт», цель недели 10 заданий |
| Тренер 💪 | 5–9 | очки опыта ⚡, уровни «Новичок → Ученик → Знаток → Мастер → Эксперт», цель недели 15 заданий |
| Стратег 🎯 | 10–11 | без игровых очков: цель недели 25 заданий, точность с первой попытки, закреплённые темы |

У всех — серия учебных дней 🔥 (выходные её не прерывают) и 16 достижений. Всё видно в «🏆 Награды»,
а короткая строка с очками, уровнем и целью недели — над главным меню. ИИ-репетитор тоже говорит в стиле режима.

## Оформление

- Сообщения приходят с разметкой: жирные заголовки, темы курсивом (`PRETTY_MESSAGES=true`).
- Картинки-карточки (`IMAGE_CARDS=true`): знакомство с Маячком, «📊 Прогресс», результат теста и урока с оценкой,
  грамота за новый уровень и достижение, недельный отчёт родителю. Рисуются Pillow, шрифт DejaVu (ставится в Docker-образ).
- Талисман Маячок — добрый маяк в полоску (`app/services/mascot.py`), три настроения: улыбается, радуется, подмигивает.

## Кабинет учителя

Учитель нажимает «👩‍🏫 Я учитель» при первом входе (или пишет `/teacher`) — кабинет открывается сразу, администратору приходит уведомление. Чтобы открывать кабинет только после подтверждения, поставьте `TEACHER_APPROVAL=true`. При первом входе выбирает:
**начальные классы** (классы 1–4, предмет — при каждом задании) или **учитель-предметник** (отмечает свои предметы,
классы 5–11, обычно 3–4 класса). Затем — имя, которое увидят ученики.

Класс общий для всех его учителей: первый учитель создаёт его и получает код, ученики вступают один раз
(`/join КОД` или «⚙️ Настройки → 🏫 Класс»), остальные учителя подключаются по тому же коду
(«➕ Добавить класс → 🔑 Подключиться по коду»). Каждый учитель видит учеников, слабые темы по своим предметам,
даёт задания по своим предметам (по теме из КТП, по слабой теме или своей) и видит результаты только своих заданий.
После теста ученик присылает фото решения — учитель видит, кто прислал, и открывает фото. Удалить класс может
только его создатель, остальные учителя — выйти из него.

Плюшки кабинета:
- ⚡ «Сегодня по программе» — тема урока по КТП, задать классу одной кнопкой.
- ⏰ Срок сдачи (завтра / пятница / неделя): накануне в 18:00 бот напоминает несдавшим, после срока — итог учителю.
- 🗺 Карта тем — «ученик × тема» цветами: знает / изучает / подтянуть.
- ⭐ Звёзды недели (по старанию, не по оценкам) и 🏅 грамоты ученикам картинкой.
- 📢 Объявление классу — ученикам и, по желанию, их родителям.
- 📥 Excel — оценки за задания, неделя учеников и карта тем; файл приходит учителю в чат (`app/services/xlsx.py`, без сторонних библиотек).

## Мини-приложение

Страница и API встроены в бота (порт `WEBAPP_PORT`, по умолчанию 8080). В приложении работает всё, что есть в боте:

- регистрация с выбором роли — ученик, родитель (по коду ребёнка), учитель;
- 💬 чат с Маячком прямо в приложении: текст, 📷 фото задачи или домашки, 🎤 голос, 🔊 озвучка ответов;
- главная (уроки на сегодня, что пора повторить), 🎯 тренажёр, 📊 прогресс, 🗓 расписание;
- 🎮 игры: «Мой маяк», «Сундук дня» и альбом наклеек, «⚡ Молния», 🃏 карточки;
- ⚙️ настройки: имя, класс, голос, увлечения, код для родителя, вступление в класс, удаление данных;
- кабинет родителя (отчёт, прогресс, расписание ребёнка) и кабинет учителя (классы, задания, результаты, фото решений);
- ❓ гайд «Как пользоваться» для каждой роли — открывается сам при первом входе и по кнопке ❓.

Каждый запрос подписан MAX (`initData`), сервер проверяет подпись токеном бота. Открытое не из MAX — показывает
демо-режим (`?demo=new`, `?demo=teacher`, `?demo=parent`). Как подключить в MAX — `docs/MINIAPP.md`,
HTTPS на сервере — `docs/SERVER.md`.

## Данные и копии

- Профили учеников и итоги диагностики хранятся в PostgreSQL. Таблицы создаются автоматически при запуске бота.
- Redis сохраняет состояние на диск, так что незаконченная диагностика переживает перезапуск.
- Сервис `db-backup` раз в сутки кладёт копию базы в папку `backups/` (14 последних). Папка не попадает в git:
  в ней данные учеников.

## Безопасность

- **Согласие на обработку данных** (`CONSENT_REQUIRED=true`): перед знакомством бот показывает, что хранит, и ждёт «✅ Согласен».
  До согласия имя не сохраняется и тексты не уходят в нейросеть. За детей младше 14 лет согласие даёт родитель (152-ФЗ).
  Ученикам, которые были до появления согласия, бот один раз показывает его при `/start`. Политика — `/privacy`,
  контакт для неё — `PRIVACY_CONTACT` в `.env`. Удаление данных стирает и согласие, и связи с родителями.

- Токены и ключи хранятся только в `.env` (он в `.gitignore` и `.dockerignore`), в коде их быть не должно.
- Если ключ попал в чат, архив или коммит, перевыпустите его.
