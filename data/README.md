# Банк заданий

Бот **сначала** ищет задание здесь и только если подходящего нет, составляет тренировочное задание с помощью ИИ
(это можно запретить в `.env`: `ALLOW_AI_TASKS=false`). Файлы можно менять **без перезапуска бота**.

Бот читает два файла, можно заполнять любой из них или оба:

- **`tasks.csv`** — таблица, которую удобно вести в Excel. Начните с копии `tasks_template.csv`.
- **`tasks.json`** — то же самое в формате JSON (пример в `tasks.example.json`).

## Таблица `tasks.csv`

| Столбец  | Что писать |
|----------|------------|
| тип      | `экзамен` (ВПР, ОГЭ, ЕГЭ) или `обычное` (обычная учёба) |
| экзамен  | `ВПР`, `ОГЭ` или `ЕГЭ`; для обычных заданий оставьте пустым |
| класс    | число от 1 до 11 |
| предмет  | как на кнопке: Математика, Русский язык, Окружающий мир, История, Геометрия... |
| тема     | тема задания; по ней бот ищет, когда ученик пишет тему. Можно пустой |
| задание  | полный текст задания |
| ответ    | верный ответ (число, слово, номер варианта). С ним бот проверяет ответ ученика |
| источник | откуда задание, например «ФИПИ, демоверсия ВПР 2026» |
| ссылка   | ссылка на источник, можно пустой |
| варианты | 2–4 варианта ответа через `|`, например `6 | 7 | 8` — бот покажет их кнопками. Верный ответ должен совпадать с одним из вариантов. Можно пусто |
| картинка | имя файла картинки из папки `data/images` (например, `vpr6-bio-1.png`), если задание с рисунком. Иначе пусто |

Сохранять в Excel: «Файл → Сохранить как → тип файла **CSV UTF-8 (разделитель — запятая)**» или
«CSV (разделители — точка с запятой)». Бот понимает оба варианта.

Если строка заполнена с ошибкой, бот её пропустит и напишет в лог, какая строка и что не так.

## Задания с рисунками

Бот отправляет картинку вместе с заданием. Положите файл (PNG или JPG) в папку `data/images` и впишите его имя в столбец
«картинка». Если в тексте задания есть «на рисунке», «схема», «график» и т. п., а картинки нет, бот такое задание
**пропустит** (и напишет об этом в лог), чтобы ученик не получил задание без рисунка.

## Откуда брать задания

Используйте материалы, которые вы вправе использовать: демоверсии, образцы и открытые банки заданий ФИПИ, задания
учителя, свои. Указывайте источник в столбце «источник». Автоматически копировать закрытое содержимое платформ
(ЯКласс, ФГИС «Моя школа», ЦОК) нельзя: у них свои правила использования и авторские права.

## Диагностика (первый тест ученика)

Вопросы диагностики лежат в отдельных файлах `diagnostic_<класс>.csv` (например, `diagnostic_4.csv`). Бот находит их сам:
достаточно положить файл в папку `data`. Если для класса файла нет, бот диагностику не предлагает и сразу показывает меню.

Столбцы: `тип` (всегда `диагностика`), `класс`, `предмет`, `уровень` (1 — лёгкий, 2 — средний, 3 — сложный), `тема`,
`задание`, `варианты` (для 1–4 классов обязательно — не все умеют писать), `ответ`, `источник`. Тема важна: по неверным ответам бот запоминает темы, которые стоит подтянуть.
